# Car photos

Put one photo per car in this folder, named `<car id>.jpg`. The site loads
`/cars/<car id>.jpg` automatically. A car without a file falls back to the
vector illustration, so you can add photos gradually.

- Landscape, roughly 16:10 (e.g. 1600x1000), side-front three-quarter view, car centred.
- Keep each file under ~250 KB (use JPG or WebP quality 75-80).
- Use photos you are licensed to use: your own, Unsplash/Pexels (check the licence),
  or manufacturer press images. Don't hot-link or copy photos from other rental sites.
- To use a different filename or a remote URL, set `"images": ["..."]` on that car in
  `src/mocks/data/cars.json` instead.
